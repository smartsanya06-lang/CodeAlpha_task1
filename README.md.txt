## How to Run

### 1. Install a C Compiler

You can use GCC, MinGW, or another C compiler.

### 2. Compile a Program

Example:

```bash
gcc calculator.c -o calculator
```

### 3. Run the Program

On Windows:

```bash
calculator.exe
```

On Linux/macOS:

```bash
./calculator
```

Repeat the same process for the other C programs.
